Un libro para aprender Julia viendo cómo piensa cada programa: línea a línea, con la memoria a la vista. Es el tercero de la colección, después de los de Python y R, y está hecho con el mismo método. Cada idea parte de una situación cotidiana, se construye con código y se comprueba visualizando la ejecución.

Julia es un lenguaje pensado para el cálculo científico: se escribe casi como las matemáticas de la pizarra y corre tan rápido como los lenguajes compilados. Este libro cuenta las dos cosas: cómo se escribe y por qué es rápido.

## Un libro, dos rutas

Como los programas del IB con su nivel medio y su nivel superior, este libro tiene **dos rutas** que conviven en las mismas páginas.

- La **ruta base** es la que sigue todo el mundo: la idea con un ejemplo hecho, el código visualizado paso a paso y los ejercicios. Sirve para clase y para aprender solo.
- Los apartados **A fondo** llevan una cápsula negra. Cuentan cómo funciona Julia por dentro y cómo se trabaja con ella como profesional. Se pueden saltar sin perder el hilo.
